Problem and design

  • Keep a robot centered on a black line while ambient light keeps changing the sensor readings, on three different tracks.
  • Photoresistor array under a close-fitting 3D-printed light shield: ambient light was the largest noise source, so I blocked it before any filtering.
  • PID on line position; three pots tune P, I, D and speed without re-flashing, so each event got its own settings.

Lessons

  • A good controller still fails on an inconsistent platform: taping the ball wheel flat was the most useful change on competition day.
  • Fix the signal at the sensor (shielding) before fixing it in software.
  • Re-tune per task: the best trade between speed and accuracy changed with the track.

Project Overview

My team built a line-following robot for the ECE 5 Lab 4 competition. The robot uses an array of photoresistors to detect a black line on a white surface, and a PID control loop to keep itself centered on the line, correcting motor speeds in real time based on the detected position relative to center.

Drag Race — 1st Place

For the drag race, we prioritized raw straight-line speed. Running maximum motor output with a low proportional gain (P=40) kept corrections fast but minimal, since the track had few sharp turns.

PID Control System

Error is computed as the actual line position minus the desired center. Three terms combine to correct motor speeds each control loop iteration:

P
Proportional
Corrections based on current error magnitude
I
Integral
Corrects steady-state error by accumulating past errors over time
D
Derivative
Predicts future error from rate of change, damping oscillation

Hardware: Early Build and Modifications

We started with a breadboard layout to prototype the circuit before committing to final wiring. We later designed a custom lightshield to block ambient light from the photoresistors, which was the single largest source of noise in the line-detection signal.

Early build stage — breadboard layout before chassis modifications. The final robot consolidated all wiring to reduce interference with the lightshield.

Tuning Strategy

We retuned the PID for each event, because the optimal tradeoff between correction speed and accuracy changed with the track geometry.

  • Drag Race — max speed (nominal 200, pot 60), P=40, I=100, D=100. Prioritized raw speed on a track with few sharp turns.
  • Frequency Sweep — slower speed (nominal 30, pot 100), P=100, I=100, D=100. Increasingly tight curves demanded aggressive correction at the expense of speed.
  • Circuit Loop — balanced (nominal 150, pot 70), P=95, I=100, D=100. Smooth, fast sustained laps.

Chassis and CAD

We modified the base chassis in CAD to improve reliability: motor mount clearances, board routing channels, and a close-fitting lightshield box that seats over the photoresistor array.

Updated chassis (left) with motor mounts and board clearance cutouts; lightshield (right) — a close-fitting enclosure that blocks ambient light from the photoresistor array

Competition Day

Late in the competition, we found that the ball wheel was inconsistently making contact with the track, alternately rolling and lifting, which introduced unpredictable speed changes. Taping it in a fixed position ensured consistent ground contact throughout each run.

Key Takeaway

The key lesson for us was that predictability in the mechanical system matters just as much as the control algorithm. A well-tuned PID controller still fails if the physical platform behaves inconsistently. The ball wheel fix was the most impactful single change on competition day.
